# Unicorner palette

One palette for every screen. Art, kits, trophies and the five rarity tiers keep their own colours.

| Name | Hex | Use |
| --- | --- | --- |
| Paper | `#fbf6e8` | Light cards, tickets, page backgrounds |
| Cream | `#f6eed8` | Soft panels inside light cards |
| Sand | `#e9dfc2` | Tracks, dividers, secondary text on dark |
| Ink | `#1d1a2b` | Text, outlines, dark inner boxes (inputs, timers) |
| Gold | `#f2c230` | Main buttons, highlights, the timer |
| Grass | `#2f9a62` | Play buttons, progress, success |
| Clay red | `#c8473b` | Headers, misses, warnings |
| Marine navy | `#1d4486` | Dark cards: the question card, level bar, leaderboard headers, footer |
| Marine light | `#2d5aa0` | Inactive tiles on marine |

Rarity tiers (keep): Tap-in `#cfd8e6`, Header `#7fe0a8`, Volley `#b48cff`, Bicycle kick `#ff7ac8`, Screamer `#ffd23f`.

Fonts: Jersey 15 (titles, buttons), VT323 (labels, timers), Barlow (questions, reading text).

In code: `index.html` defines these as `--p-*` variables in the `<style id="palette">` block at the end of the page.
