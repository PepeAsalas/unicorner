Batch 3 for the football tycoon game, same chat, same style and camera angle as everything so far (cool, not cute; club red and cream; pixel art; plain white background). Every image is a still frame: anything that moves is a sprite sheet with frames side by side in one row, all the same size, the object in exactly the same spot in each frame. When everything is done, put all files in one zip called unicorner-tycoon-batch-3.zip.
