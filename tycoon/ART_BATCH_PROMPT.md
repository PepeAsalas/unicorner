EVERY IMAGE IS A STILL FRAME
- Nothing is in motion inside an image: no motion blur, no speed lines, no swoosh marks, no smoke trails, no "action" effects.
- Anything that moves in the game comes as a sprite sheet: several still frames side by side in ONE row, every frame the same size, evenly spaced, the character or object in exactly the same spot in each frame so only the moving part changes.
- Plain white background on everything.

BUILDINGS (same rules as the stadiums)
- Same isometric camera angle as the stadiums. The footprint is a diamond with corners pointing up, down, left and right, filling the width of the image.

- All 4 stages of one building: same image size, same footprint, same angle, so a stage can replace the one before without moving.
- Stage 1 is poor and scrappy, stage 2 decent, stage 3 big and modern, stage 4 absurdly rich (gold, glass, a helipad...). Each stage clearly grows from the one before, like the stadiums did.
